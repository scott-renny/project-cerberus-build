# Security and Privacy

This repository documents a personal workstation and must remain safe for public viewing.

## Never publish

- Passwords, tokens, recovery codes, or product keys
- Private keys, certificates, VPN profiles, or environment files
- Serial numbers, invoices containing personal details, or device identifiers
- Public IP addresses or detailed private network addressing
- Hostnames, usernames, Wi-Fi details, or unsanitized configuration exports
- Screenshots containing notifications, account details, or browser sessions
- Live malware or suspicious samples

Use placeholders such as `192.0.2.10`, `example.local`, and `<REDACTED>`. Review staged changes and image metadata before every public push.

## Reporting a problem

If sensitive information is committed, remove it from public access, rotate the affected secret immediately, and then clean the Git history where necessary.
