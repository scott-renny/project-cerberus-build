# Changelog

All notable changes to Project Cerberus are recorded here.

## [Unreleased]

### Changed

- Replaced the superseded Fedora KDE direction with Linux Mint Cinnamon.
- Replaced Fedora package and lifecycle guidance with Linux Mint/Ubuntu `apt`, Update Manager, and supported vendor repositories.
- Replaced SELinux and firewalld assumptions with AppArmor and UFW.
- Replaced the Fedora deployment and update runbooks with Linux Mint-specific procedures.
- Aligned the six-display Cinnamon workflow, NVIDIA Driver Manager, backup, recovery, Wazuh, Docker, and validation plans.
- Updated the COC Phase 8.5 and portfolio references to the Linux Mint decision.

## [0.2.0] — Superseded Fedora planning baseline

The repository previously documented Fedora KDE as the intended Cerberus platform. That direction was superseded before implementation; its evolution remains visible in Git history.

## [0.1.0]

### Added

- Initial repository structure and early dual-GPU, six-monitor hardware-build planning.
