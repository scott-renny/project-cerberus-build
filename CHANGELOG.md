### Changed

- Replaced the stale Windows maintenance reference with Fedora package, kernel, Flatpak, firmware, NVIDIA, Wazuh, and recovery checks.
- Renamed the project concept from a PC build log to a complete Fedora Linux engineering workstation and COC command-platform program.
- Replaced Windows 11 Pro with Fedora KDE Plasma as the locked host OS.
- Replaced WSL/Docker assumptions with Fedora-native Podman, Distrobox, and optional KVM/QEMU.
- Replaced Windows hardening assumptions with encryption, SELinux, firewall, Secure Boot planning, recovery, and hardware-key integration.
- Defined Cerberus as the trusted interactive operator/control workstation, not a permanent server or Kubernetes node.
- Consolidated Project Hydra into Cerberus; preserved Project Hermes for the Windows 11 laptop.
- Locked AMD Ryzen 9 9900X, MSI MAG CORELIQUID A15 360, Corsair RM850e (2025), and CyberPower CP1500PFCLCD decisions.
- Locked 64 GB DDR5-6000 EXPO, 2 TB NVMe, and RTX 5060 Ti 16 GB specifications while leaving exact purchasable models open where appropriate.
- Locked the secondary-GPU direction to compact NVIDIA hardware, with T400 preferred and P620 fallback.
- Made OBS and streaming the final deployment phase.
- Revised the preliminary core budget to CA$3,000+ before tax, excluding the case.
