# Upgrade Roadmap

Upgrades are need-driven rather than date-driven.

## Storage

Add a second 2 TB or 4 TB NVMe SSD when free space, VM activity, or project separation justifies it. Confirm motherboard lane-sharing before installation.

## Memory

Consider 128 GB only when measured VM and container workloads regularly approach the installed 64 GB. Four-DIMM operation may require a lower memory speed.

## Networking

Consider faster-than-2.5 Gb Ethernet only when the switch, server, cabling, and actual transfer workloads can benefit.

## Graphics

Replace the primary GPU only when measured gaming, AI, encoding, or editing requirements exceed it. Preserve the auxiliary display strategy unless a simpler single-card solution can drive all required displays.

## Power protection

Add a suitably sized UPS after measuring real system load and confirming the desired runtime and graceful-shutdown requirements.
