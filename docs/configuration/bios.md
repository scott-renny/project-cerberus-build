# BIOS Configuration

Record the motherboard model, BIOS version, update date, and source link before changing settings.

## Baseline checklist

- [ ] Load optimized defaults after the BIOS update.
- [ ] Confirm CPU, 64 GB memory, and SSD detection.
- [ ] Enable the memory profile only after baseline testing.
- [ ] Enable SVM/AMD virtualization.
- [ ] Confirm UEFI boot, Secure Boot, and TPM settings for Windows 11.
- [ ] Enable Resizable BAR if supported by the final configuration.
- [ ] Review fan curves after thermal testing.
- [ ] Save a sanitized configuration summary.

Change one performance-related setting at a time and retest stability after each change.
